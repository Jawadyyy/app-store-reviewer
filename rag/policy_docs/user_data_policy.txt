Google Play User Data Policy
==============================

1. CONTACTS ACCESS: Apps that request READ_CONTACTS or
   WRITE_CONTACTS must clearly justify why contact access
   is needed for core app functionality. Usage must be
   disclosed in the privacy policy.

2. MINIMAL DATA COLLECTION: Apps must only collect user
   data that is necessary for the stated functionality.
   Collecting excess data is a policy violation.

3. PRIVACY POLICY: All apps that collect user data must
   have a valid privacy policy linked in the Play Store
   listing. The policy must clearly explain what data
   is collected and how it is used.

4. DATA STORAGE: User data must be stored securely.
   Sensitive data must be encrypted both in transit
   and at rest.

5. THIRD PARTY SHARING: Apps must clearly disclose if
   user data is shared with third parties. Users must
   be given the option to opt out where possible.

6. PHONE STATE: Apps requesting READ_PHONE_STATE must
   justify the need based on core functionality. Simply
   reading device identifiers without clear purpose
   is not permitted.

7. EXTERNAL STORAGE: Reading or writing external storage
   requires clear justification. Apps must not access
   files outside their own app directory without explicit
   user consent.
